# Opaque replace-whole values

Use this reference whenever focused `read` reports `type: opaque`.

1. Focused-read the exact target and copy its complete replacement document.
2. Edit only the intended payload data; preserve every other emitted field and class detail.
3. Submit one `apply` set card, first as `dryRun: true`, then unchanged to the owned output.
4. Require the receipt and focused-read the output to prove the edit and obtain the next current document.

Opaque documents are target-bound. On stale digest/fingerprint, class, payload, or target rejection, refresh the exact property and reapply the semantic edit to the newly emitted document.
